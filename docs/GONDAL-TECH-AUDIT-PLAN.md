## Five persona passes

- Paper-to-digital: setup comprehension, terminology and recovery without remembered cross-screen information.
- Mobile dispatcher: urgent enquiry lookup, thumb-friendly controls and quick return to the work list.
- Operations hawk: repeat price edits, minimizing duplicate entry, search and reliable save status.
- Commercial estimator: price/options/scoping clarity; proposal/dispatch expectations remain product-fit questions.
- Solo operator: interruption, resume, unsaved changes and rapid daily follow-up.

Each pass uses the same new business with a documented reset or isolated scenario state. Do not silently reset server data or erase earlier evidence. Record which actions are repeatable, which changed state, and what remains in the account.
